# MJC Designs AI Design Assistant for Bricks Builder

An informational website for the free, open-source WordPress plugin. This edition covers v1.1.8, including the optional Style Manager for shared colors and variables in the Main and Content to Pages workspaces. It includes eight release screenshots (14–21) in a dedicated Style Manager gallery, plus 43 earlier plugin screenshots in three workspace galleries, enlarged views with captions, and playable previews of the four videos on the [MJC Designs AI Design Assistant YouTube channel](https://www.youtube.com/@MJCDesignsAIDesignAssistant). The site keeps the plugin-inspired dark theme and animated icon. It is plain HTML, CSS, and JavaScript, so GitHub Pages can serve it directly without a build step.

## Publish with GitHub Pages

1. Open this repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published address in the Pages settings.

## Update the site

Upload `index.html`, `README.md`, and the complete `assets/` folder, including `assets/screenshots/` and `assets/style-manager/`, to the repository root on the `main` branch, replacing the earlier versions. Keep `LICENSE` in the repository. GitHub Pages will publish the update automatically after the commit.

The animated GIF in `assets/` is the plugin icon. The static SVG icon appears for visitors who prefer reduced motion.
