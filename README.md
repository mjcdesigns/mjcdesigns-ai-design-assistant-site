# MJC Designs AI Design Assistant for Bricks Builder

An informational website for the free, open-source WordPress plugin. This edition covers v1.1.7, including the Content to Pages Workspace, page-to-page design references, and browser alerts. It includes 43 plugin screenshots in three browsable workspace galleries, enlarged views with captions, and playable previews of the four videos on the [MJC Designs AI Design Assistant YouTube channel](https://www.youtube.com/@MJCDesignsAIDesignAssistant). The site keeps the plugin-inspired dark theme and animated icon. It is plain HTML, CSS, and JavaScript, so GitHub Pages can serve it directly without a build step.

## Publish with GitHub Pages

1. Open this repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published address in the Pages settings.

## Update the site

Upload `index.html`, `README.md`, and the complete `assets/` folder, including `assets/screenshots/`, to the repository root on the `main` branch, replacing the earlier versions. Keep `LICENSE` in the repository. GitHub Pages will publish the update automatically after the commit.

The animated GIF in `assets/` matches the v1.1.7 plugin package. The static SVG icon appears for visitors who prefer reduced motion.
