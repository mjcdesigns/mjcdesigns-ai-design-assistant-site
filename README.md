# MJC Designs AI Design Assistant for Bricks Builder

An informational website for the free, open-source WordPress plugin. Current plugin version: v1.1.11. The site highlights the five interface color themes introduced in v1.1.11 with the release image and includes the complete plugin Version History. It also covers the v1.1.9 Page SEO editor for selected WordPress pages, initial Yoast SEO and AIOSEO support, and labeled SEO details from uploaded copy. It also covers the v1.1.8 Style Manager and includes eight Style Manager release screenshots (14–21), 43 earlier plugin screenshots in three workspace galleries, enlarged views with captions, and playable previews of four videos on the [MJC Designs AI Design Assistant YouTube channel](https://www.youtube.com/@MJCDesignsAIDesignAssistant). The site keeps the plugin-inspired dark theme and animated icon. It is plain HTML, CSS, and JavaScript, so GitHub Pages can serve it directly without a build step.

## Publish with GitHub Pages

1. Open this repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published address in the Pages settings.

## Update the site

For v1.1.11, replace `index.html`, `README.md`, `assets/styles.css`, and `assets/site.js` in the repository, and add `assets/color-themes.png`. Keep their folder paths. The existing screenshots, icon, and license files do not need to be uploaded again. GitHub Pages will publish the update after the commit.

The animated GIF in `assets/` is the plugin icon. The static SVG icon appears for visitors who prefer reduced motion.
