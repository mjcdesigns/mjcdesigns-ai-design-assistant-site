# MJC Designs AI Design Assistant for Bricks Builder

An informational website for the free, open-source WordPress plugin. Current plugin version: v1.1.13. The site highlights broader page, SEO, and heading format recognition in Content to Pages and its detected-structure preview. It also features the five interface color themes introduced in v1.1.11, the v1.1.9 Page SEO editor, and the v1.1.8 Style Manager. The complete Version History, alpha testing invitation, eight Style Manager release screenshots (14–21), 43 earlier plugin screenshots in three workspace galleries, enlarged views with captions, and four playable video previews are included. Visit the [MJC Designs AI Design Assistant YouTube channel](https://www.youtube.com/@MJCDesignsAIDesignAssistant) for more tutorials. The site keeps the plugin-inspired dark theme and animated icon. It is plain HTML, CSS, and JavaScript, so GitHub Pages can serve it directly without a build step.

## Publish with GitHub Pages

1. Open this repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Wait for the Pages deployment to finish. GitHub will show the published address in the Pages settings.

## Update the site

For v1.1.13, replace `index.html` and `README.md` in the repository. Keep their folder paths. GitHub Pages will publish the update after the commit.

The animated GIF in `assets/` is the plugin icon. The static SVG icon appears for visitors who prefer reduced motion.
