CONTENT TO PAGES WORKSPACE

Bring the words. Shape the pages.

Preview the extracted copy, add brand colors and instructions, then create WordPress drafts. Generate and refine a Bricks design for each page when you are ready.

Draft firstPages remain drafts after design changes. Publishing requires a separate confirmation and permission.
  1. 01

    Prepare your copy

    Upload a DOCX or text-based PDF with a clear title for each page, such as Page: Home. Files can be up to 50 MB, subject to your server's upload limit.

  2. 02

    Set the direction

    Choose brand colors and add design instructions. Your planner settings stay in this browser tab; the uploaded file must be added again after a reload.

  3. 03

    Create draft pages

    Generate WordPress drafts from the copy. If a title already exists, the plugin asks before skipping that page.

  4. 04

    Review each design

    Generate or refine a Bricks design for a selected page, inspect the temporary preview and changes, then apply. You can also edit an existing Bricks template.

Choose the right file: DOCX retains common bold, italic, and safe external links for Bricks text proposals. PDF extraction reads supported text and groups paragraphs where possible, but does not retain formatting or links. Image-only scans may not extract correctly.

GETTING STARTED

Quick start

Use the main workspace to take a page from request to reviewed change in five steps.

03 / 06

  1. Connect your AI provider

    A site administrator configures a compatible provider under WordPress Settings → Connectors. Choose an available model in the assistant.

  2. Enable Bricks abilities

    Under Bricks → AI → Abilities, enable get-page-elements, set-page-elements, and get-element-schema.

  3. Select a page or template

    Choose an editable WordPress page or Bricks template. Pages without Bricks elements can be selected too.

  4. Describe the change

    Optionally attach a JPG, PNG, or WebP reference image up to 5 MB, choose up to five Media Library images, or name another editable page for design guidance.

  5. Review, then apply

    Check the frontend preview and proposed edits across desktop, tablet, and mobile. Apply when ready; use Undo or Redo for the last assistant change.

HELP CENTER

Frequently asked questions

06 / 06
Can Content to Pages make a full website?

It can create WordPress draft pages from your final copy and prepare a separate Bricks design for each page. Review and apply each proposal, then publish pages separately. It does not create templates, set template conditions, or add SEO fields.

Should I upload DOCX or PDF copy?

Use DOCX when bold, italic, or links matter. Text-based PDFs can supply readable copy, but their formatting and links are not retained; image-only scans may not extract correctly. The extracted-copy preview is plain text for both.

Does the assistant edit blog posts?

No. It edits eligible WordPress pages and Bricks templates, and Content to Pages creates draft pages. It can configure supported Query Loops to display existing posts, but does not edit or create blog posts.

Can I use images from my Media Library?

Yes. Choose up to five existing site images, then describe where you want them placed. Their metadata goes to the selected provider, but the selected image files do not. The plugin can propose labeled native placeholders for missing visuals.

Can I match another page's design?

Yes. Select the page you want to change and name one other editable page in your prompt. The assistant receives a compact summary of that page's native Bricks layout and visual settings. It does not change the reference page or copy its words and images.

Does the HTML & CSS Workspace change my page?

No. It generates and refines a draft independently of the selected page. Preview it in the isolated browser frame, then copy the HTML and CSS into Bricks yourself. Review the resulting classes, styles, and images in Bricks before saving.

Where are HTML and CSS chats kept?

Up to five chats stay in the current browser tab's session storage until the tab or chat is closed. The plugin does not save those chats to WordPress.

Can the plugin notify me when a request finishes?

When a design request finishes or fails while the workspace is unattended, an unread count appears in the browser tab title. You can enable optional desktop alerts from the workspace header. Browser permission and an open tab are required.

Does using an AI provider cost money?

It depends on your selected provider and model. Some offer free usage tiers, while others charge. Review the provider's current terms, prices, quotas, and data-handling policies before use.

Are previews permanent?

No. Main and Content to Pages previews are private temporary drafts removed when you leave or replace them, with a one-hour expiration fallback. HTML and CSS designs appear in an isolated browser frame. WordPress draft pages created from copy remain until you publish or delete them.
