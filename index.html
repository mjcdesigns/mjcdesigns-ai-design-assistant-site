GETTING STARTED

Quick start

From provider setup to a reviewed change in five steps.

01 / 04

  1. Connect your AI provider

    A site administrator configures a compatible provider under WordPress Settings → Connectors. Choose an available model in the assistant.

  2. Enable Bricks abilities

    Under Bricks → AI → Abilities, enable get-page-elements, set-page-elements, and get-element-schema.

  3. Select a page or template

    Choose an editable WordPress page or Bricks template. Pages without Bricks elements can be selected too.

  4. Describe the change

    Optionally attach a JPG, PNG, or WebP reference image up to 5 MB, or choose up to five existing Media Library images for placement.

  5. Review, then apply

    Check the frontend preview and proposed edits. Apply when ready; use Undo to reverse the last assistant change.

CURRENT BOUNDARIES

Focused on page elements

This release does not create or edit WordPress post records, manage global classes or variables, theme styles, components, WooCommerce setup, or template conditions. Proposals cannot write code controls or Custom CSS.

REVIEW & DATA

Know what happens before you apply.

The plugin makes its workflow and provider data sharing clear.

03 / 04
◇

A temporary preview

Suggestions are checked against the live Bricks control schema and shown in a temporary frontend preview. Changes are saved only after you choose Apply changes to page.

⌁

Your selected provider

Your prompt, selected page content, optional reference image, and metadata for explicitly selected Media Library images are sent to the selected provider. The Media Library image files are not sent by this feature.

▢

Your site, your backup

Reference uploads are not saved in the Media Library. Provider prices, quotas, and data handling vary. Keep a backup before applying generated changes, especially on a live page.

HELP CENTER

Frequently asked questions

04 / 04
Does the assistant edit blog posts?

No. It edits WordPress pages and Bricks templates. It can configure supported Query Loops to display existing posts, but it does not edit blog post content or create post records.

Can I use images from my Media Library?

Yes. Choose up to five existing site images, then describe where you want them placed. Image metadata goes to the selected provider; this feature does not send the selected image files for visual analysis.

Does using an AI provider cost money?

It depends on your selected provider and model. Some offer free usage tiers, while others charge. Review the provider's current terms, prices, quotas, and data-handling policies before use.

Are previews permanent?

No. The assistant creates private temporary draft previews. It removes them when you leave the workspace, replace a preview for the same document, or when the one-hour expiration fallback runs.
