ABOUT THE ASSISTANT

Made for thoughtful Bricks workflows.

MJC Designs AI helps you review native Bricks page changes, create standalone HTML and CSS concepts, and prepare draft pages from final copy. Optional Style Manager settings can guide designs in the Main and Content to Pages workspaces. Page SEO can edit supported metadata for selected WordPress pages. It uses the WordPress AI Client with provider models configured through Settings → Connectors.

Initial integrationsYoast SEO and AIOSEO are supported where the active installation and your account allow the relevant fields. The slug is saved through WordPress.

Preview before saving

Check the title, page URL, and description together. The length indicators are estimates, not scores from an SEO tool. Changing a published slug needs confirmation and may need a redirect.

Bring SEO from copy

Content to Pages recognizes clearly labeled SEO details in each uploaded page section. They appear as reviewable suggestions; uploading and extracting alone do not save them.

Save with new drafts

Generate Drafts can save labeled SEO details when exactly one supported SEO tool is active. If no slug is supplied, WordPress handles it. With multiple active tools, the SEO details stay for review and Page SEO shows a warning.

Scope: Page SEO is for selected WordPress pages, not Bricks templates, blog posts, or the HTML & CSS Workspace. The plugin is independent of Yoast SEO and AIOSEO and is not affiliated with or endorsed by their developers.

OPTIONAL STYLE MANAGER

Set the palette. Shape the scales.

Create palette colors and dark counterparts, tune individual shades, and define fluid typography and spacing. When enabled, the assistant can use these settings in compatible Bricks controls while you review its proposals.

Works with BricksImport or export Bricks-compatible JSON for colors and variables. Review the generated design and import the JSON into Bricks separately.

Colors and shades

Edit palette colors with a color picker, adjust light and dark shade steps, and restore generated values when needed.

Fluid scales

Set typography and spacing ranges, preview the results, and choose root font size and viewport widths for fluid calculations.

Shared guidance

Use the palette in Website Planner and carry shared settings into a continued session. New page designs can favor your primary and secondary colors.

How to use it: Open Style Manager from the Main or Content to Pages workspace, enable it, then save your settings. Export JSON if you want the matching colors and variables in Bricks. Review every proposed change before applying it.

From final copy to draft pages.

Content to Pages keeps page creation and design review in separate steps.

05 / 10
CONTENT TO PAGES WORKSPACE

Bring the words. Shape the pages.

Preview the extracted copy, add brand colors and instructions, then create WordPress drafts. Clearly labeled SEO details can follow new drafts when one supported SEO tool is active. Generate and refine a Bricks design for each page when you are ready.

Draft firstPages remain drafts after design changes. Publishing requires a separate confirmation and permission.
  1. 01

    Prepare your copy

    Upload a DOCX or text-based PDF with a clear title for each page, such as Page: Home. You can include labeled SEO title, keyphrase, slug, and meta description. Files can be up to 50 MB, subject to your server's upload limit.

  2. 02

    Set the direction

    Choose brand colors and add design instructions. Your planner settings stay in this browser tab; the uploaded file must be added again after a reload.

  3. 03

    Create draft pages

    Generate WordPress drafts from the copy. If a title already exists, the plugin asks before skipping that page. Labeled SEO details can be saved with each new draft when one supported SEO tool is active.

  4. 04

    Review each design

    Generate or refine a Bricks design for a selected page, inspect the temporary preview and changes, then apply. You can also edit an existing Bricks template.

Choose the right file: DOCX retains common bold, italic, and safe external links for Bricks text proposals. PDF extraction reads supported text and groups paragraphs where possible, but does not retain formatting or links. Image-only scans may not extract correctly. There is no fixed page-count limit; your server may impose an upload limit below 50 MB.

GETTING STARTED

Quick start

Use the main workspace to take a page from request to reviewed change in five steps.

06 / 10

  1. Connect your AI provider

    A site administrator configures a compatible provider under WordPress Settings → Connectors. Choose an available model in the assistant.

  2. Enable Bricks abilities

    Under Bricks → AI → Abilities, enable get-page-elements, set-page-elements, and get-element-schema.

  3. Select a page or template

    Choose an editable WordPress page or Bricks template. Pages without Bricks elements can be selected too.

  4. Describe the change

    Optionally attach a JPG, PNG, or WebP reference image up to 5 MB, choose up to five Media Library images, or name another editable page for design guidance.

  5. Review, then apply

    Check the frontend preview and proposed edits across desktop, tablet, and mobile. Apply when ready; use Undo or Redo for the last assistant change.

CURRENT BOUNDARIES

Review each result

The main and Content to Pages workspaces change registered native Bricks controls; neither writes code controls or Custom CSS. The HTML & CSS Workspace makes drafts for manual copying. Content to Pages creates WordPress pages as drafts, but does not create templates or set template conditions. Page SEO separately edits supported metadata on selected WordPress pages; labeled SEO details can also be saved with a new draft when one supported tool is active.

REVIEW & DATA

Know what happens before you apply.

The plugin makes its workflows and provider data sharing clear.

08 / 10
◇

Preview before applying

Main and Content to Pages design proposals use private temporary frontend previews. WordPress draft pages created from copy persist, while publishing requires a separate confirmation.

⌁

Your selected provider

The main workspace sends your prompt and selected Bricks content. Content to Pages can also send extracted copy and planner guidance. Optional reference images and metadata for explicitly selected Media Library images may be sent; selected image files are not.

▢

Browser-session details

Chats and saved planner settings stay in the current browser tab, not in WordPress. Uploaded copy files and extracted text are not saved by the plugin; re-upload after leaving or reloading. Draft pages, applied designs, and supported SEO fields you save do persist in WordPress. Provider costs and data handling vary.

Frequently asked questions

10 / 10
Which SEO tools does Page SEO support?

The initial integration supports Yoast SEO and AIOSEO for SEO titles, meta descriptions, supported focus keyphrases, and the WordPress page slug. Available fields depend on the active tool and your account. The plugin is independent of both SEO tools.

Does uploading copy immediately save SEO details?

No. After extraction, clearly labeled SEO details appear as suggestions for each page. Generate Drafts can save those labeled details with newly created drafts when exactly one supported SEO tool is active. Later edits require Apply in Page SEO. If no slug is supplied, WordPress handles it.

What if more than one SEO tool is active?

Page SEO warns when multiple SEO tools are active because their metadata can conflict. Keep one SEO plugin active for reliable page metadata. Page SEO does not edit Bricks templates, blog posts, or HTML and CSS drafts.

Does Style Manager automatically add variables to Bricks?

No. Style Manager can guide compatible design proposals while enabled. Export its Bricks-compatible JSON and import it into Bricks separately if you want the matching colors and variables in your site.

Can Content to Pages make a full website?

It can create WordPress draft pages from your final copy and prepare a separate Bricks design for each page. Review and apply each proposal, then publish pages separately. It does not create templates or set template conditions. Its Page SEO editor can review supported metadata for selected pages, and labeled SEO details can be saved with new drafts when one supported tool is active.

Should I upload DOCX or PDF copy?

Use DOCX when bold, italic, or links matter. Text-based PDFs can supply readable copy, but their formatting and links are not retained; image-only scans may not extract correctly. The extracted-copy preview is plain text for both.

Does the assistant edit blog posts?

No. It edits eligible WordPress pages and Bricks templates, and Content to Pages creates draft pages. It can configure supported Query Loops to display existing posts, but does not edit or create blog posts.

Can I use images from my Media Library?

Yes. Choose up to five existing site images, then describe where you want them placed. Their metadata goes to the selected provider, but the selected image files do not. The plugin can propose labeled native placeholders for missing visuals.

Can I match another page's design?

Yes. Select the page you want to change and name one other editable page in your prompt. The assistant receives a compact summary of that page's native Bricks layout and visual settings. It does not change the reference page or copy its words and images.

Does the HTML & CSS Workspace change my page?

No. It generates and refines a draft independently of the selected page. Preview it in the isolated browser frame, then copy the HTML and CSS into Bricks yourself. Review the resulting classes, styles, and images in Bricks before saving.

Where are HTML and CSS chats kept?

Up to five chats stay in the current browser tab's session storage until the tab or chat is closed. The plugin does not save those chats to WordPress.

Can the plugin notify me when a request finishes?

When a design request finishes or fails while the workspace is unattended, an unread count appears in the browser tab title. You can enable optional desktop alerts from the workspace header. Browser permission and an open tab are required.

Does using an AI provider cost money?

It depends on your selected provider and model. Some offer free usage tiers, while others charge. Review the provider's current terms, prices, quotas, and data-handling policies before use.

Are previews permanent?

No. Main and Content to Pages previews are private temporary drafts removed when you leave or replace them, with a one-hour expiration fallback. HTML and CSS designs appear in an isolated browser frame. WordPress draft pages created from copy remain until you publish or delete them.
