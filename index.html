GETTING STARTED

Quick start

Use the main workspace to take a page from request to reviewed change in five steps.

02 / 05

  1. Connect your AI provider

    A site administrator configures a compatible provider under WordPress Settings → Connectors. Choose an available model in the assistant.

  2. Enable Bricks abilities

    Under Bricks → AI → Abilities, enable get-page-elements, set-page-elements, and get-element-schema.

  3. Select a page or template

    Choose an editable WordPress page or Bricks template. Pages without Bricks elements can be selected too.

  4. Describe the change

    Optionally attach a JPG, PNG, or WebP reference image up to 5 MB, or choose up to five existing Media Library images for placement.

  5. Review, then apply

    Check the frontend preview and proposed edits across desktop, tablet, and mobile. Apply when ready; use Undo or Redo for the last assistant change.

CURRENT BOUNDARIES

Two distinct workflows

The main workspace does not create WordPress posts, manage global classes or variables, theme styles, components, WooCommerce setup, or template conditions. Its proposals cannot write code controls or Custom CSS. The HTML & CSS Workspace creates drafts for manual copying and does not apply them to a page.

REVIEW & DATA

Know what happens before you apply.

The plugin makes its workflows and provider data sharing clear.

04 / 05
◇

Preview before saving

Main-workspace suggestions are checked against live Bricks controls and shown in a private temporary frontend preview. Page changes are saved only after you choose Apply changes to page.

⌁

Your selected provider

The main workspace sends your prompt, selected page content, optional reference image, and metadata for explicitly selected Media Library images. The HTML & CSS Workspace sends your prompt and optional image; refinements include the current draft.

▢

Private drafts, careful review

HTML and CSS chats stay in this browser tab's session storage, not in WordPress. Reference uploads are not saved in the Media Library. Provider costs and data handling vary; keep a backup before applying page changes.

HELP CENTER

Frequently asked questions

05 / 05
Does the assistant edit blog posts?

No. It edits WordPress pages and Bricks templates. It can configure supported Query Loops to display existing posts, but it does not edit blog post content or create post records.

Can I use images from my Media Library?

Yes. Choose up to five existing site images, then describe where you want them placed. Image metadata goes to the selected provider; this feature does not send the selected image files for visual analysis.

Does the HTML & CSS Workspace change my page?

No. It generates and refines a draft independently of the selected page. Preview it in the isolated browser frame, then copy the HTML and CSS into Bricks yourself. Review the resulting classes, styles, and images in Bricks before saving.

Where are HTML and CSS chats kept?

Up to five chats stay in the current browser tab's session storage until the tab or chat is closed. The plugin does not save those chats to WordPress.

Does using an AI provider cost money?

It depends on your selected provider and model. Some offer free usage tiers, while others charge. Review the provider's current terms, prices, quotas, and data-handling policies before use.

Are previews permanent?

No. Main-workspace previews are private temporary drafts removed when you leave or replace them, with a one-hour expiration fallback. HTML and CSS drafts appear in an isolated browser frame without creating preview posts.
